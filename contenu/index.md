# Glane

Bibliothèque collaborative de signets, où chaque fiche détaille les raisons de conserver une référence.

## Développement

- **Eleventy** : Génération de sites à partir de fichiers Markdown.
- **Pagefind** : Moteur de recherche pour les sites statiques.
- **Web Awesome** : Bibliothèque de composants d’interface personnalisables, indépendants des frameworks et basés sur les standards du Web.
- **CUBE CSS** : Méthodologie d’organisation du CSS axée sur la composition, les utilitaires, les blocs et les exceptions, tout en exploitant la cascade.
- **Vanilla JS: You Might Not Need that Library** : Conférence de Maximiliano Firtman abordant le JavaScript natif et la pertinence des bibliothèques.
- **Forgejo** : Forge logicielle libre et auto-hébergeable pour le développement et la gestion de projets en équipe.
- **Conventional Commits 1.0.0** : Spécification d’un format standardisé pour les messages de commit, précisant le type de modification et les éventuelles ruptures de compatibilité.
- **Fastify** : Framework web pour Node.js, doté d’un système de plugins et intégrant la validation et la sérialisation des schémas.
- **Hono** : Framework web fondé sur les standards du Web, compatible avec plusieurs environnements d’exécution JavaScript.

## Design

- **Design Tokens Community Group** : Groupe communautaire définissant un format commun pour l’échange de design tokens entre outils de conception et de développement.
- **Lexend** : Famille de polices conçue pour optimiser la lisibilité, proposant plusieurs variantes de largeur et d’espacement.
- **Atkinson Hyperlegible** : Famille de polices développée par le Braille Institute pour améliorer la lisibilité, en particulier pour les personnes malvoyantes.
- **Inclusive Sans** : Police sans empattement créée par Olivia King, dont la conception repose sur des critères de lisibilité et de distinction des caractères.

Ressources

- **Slidev** : Outil de création de présentations en Markdown, spécialement conçu pour les développeurs.
